⚙️ How to use

1

Open the tool you need by clicking the button above. It runs directly in your browser — no installation needed.

2

Upload the PDF template when the tool asks for it. The templates are in the templates/ folder of this repository.

3

Fill in the shipment details using the form. Your address book and settings are saved locally in your browser.

4

Generate the PDF. The filled document downloads automatically. No data is sent anywhere.

5

Back up your data regularly using the 📥 Export button in each tool. This saves your address books as a JSON file you can restore on any device.
